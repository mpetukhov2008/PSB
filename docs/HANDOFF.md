# Передача ОПОРЫ следующей команде

**Состояние: версия 1.1.0, локальный рабочий прототип.** Передавайте всю папку проекта или ссылку на зафиксированный коммит. Рабочие ключи и персональные данные в комплект не входят.

## Первые 30 минут

1. Прочитайте README и запустите `START_PSB.cmd` на Windows либо `python3 -m psb.launcher`.
2. Пройдите пять примеров из README. Убедитесь, что учебная база и отсутствие модели обозначены явно.
3. Выполните команды из [TESTING.md](TESTING.md), посмотрите последний CI для переданного коммита.
4. Изучите [API.md](API.md), затем `psb/assistant.py` и `psb/knowledge.py`.
5. До изменения поиска получите материалы организаторов из списка P0. Не подменяйте их синтетическими данными при отчёте о качестве.

## Что передаётся

| Часть | Текущее состояние | Чем проверяется |
|---|---|---|
| Запуск | CMD, Python и Docker; свободный локальный порт в быстром запуске | `test_launch.py`, Windows CI, Docker job |
| Настройки | Общий `.env`, приоритет окружения, диагностика без вызова модели | `ConfigTests`, `--check` |
| Корпус | JSON, явные интервалы редакций, отклонение пересечений | `KnowledgeTests`, `test_import.py` |
| Поиск | Лексическое BM25-подобное ранжирование, до 10 фрагментов | Тесты на учебном корпусе; полнота на реальном не измерена |
| Генерация | OpenAI-совместимый адаптер, два обращения к одной модели | Локальный тестовый HTTP API; реальный API не проверен |
| Достоверность | Проверка ID, дословности цитат, отдельная смысловая проверка | Ложные цитаты, выдуманные ID, отказ проверяющего и некорректный ответ |
| Интерфейс | Чат, источники, дата, темы, мобильный вид, JSON-выгрузка | Chromium desktop/mobile |
| Сабмит | `solution.py` с независимыми JSONL-кейсами | Локальный контракт; официальный формат пока неизвестен |

## Известные ограничения

- Только учебная база. Нет настоящего API, оценки LLM-судьи и готового официального сабмита.
- Поиск лексический: переформулировки и сложные вопросы могут не найти нужный фрагмент. Отсутствие результатов поиска не доказывает отсутствие нормы в корпусе.
- Законы считаются доступными только в текущей редакции. Если в историческом запросе найден закон, ответ блокируется консервативно. Частичный ответ по другим документам в таком смешанном запросе пока не строится.
- Документы одной `family` не могут иметь пересекающиеся периоды. Полную новую редакцию после допсоглашения готовят явно; юридическое объединение изменений не автоматизировано.
- Несколько дат требуют явного выбора даты события. Сравнение нескольких периодов в одном ответе не реализовано как отдельный режим.
- Проверяющий использует ту же модель. Совпадающие ошибки генерации и проверки возможны. Регулярные выражения ловят лишь часть попыток смены роли.
- Без модели выдаются выдержки; обоснованный юридический ответ не формируется. Реальные отказы и исправление предпосылок требуют оценки с моделью.
- Видны импортированные тексты, а не исходный PDF с координатной подсветкой. OCR отсутствует.
- Короткая история передаётся клиентом, сокращается по длине и не сохраняется сервером. После перезагрузки страницы диалог пропадает.
- Отмена в браузере прекращает ожидание, но уже идущий запрос модели может продолжаться. Таймаут задаётся на каждый из двух модельных запросов.
- HTTP-сервис предназначен для локального прототипа. Разрешены Host `localhost`, `127.0.0.1`, `::1`; произвольное доменное имя без доработки не подойдёт.

## Решения, которые нужно сохранить при доработке

1. Демо-данные всегда явно помечаются; метрики на них не называются качеством на базе организаторов.
2. Документы и история — недоверенные данные, а не системные инструкции.
3. Прошлые ответы модели не являются источниками доказательств.
4. Непрошедший проверку ответ не показывается как юридический вывод. Найденные положения остаются доступны.
5. Редакции и даты не выводятся автоматически из произвольного имени файла.
6. Ключи не должны попасть в Git, архив, HTML, экспорт результата или сообщение об ошибке.
7. Не возвращайте в проект интеграции внешнего поиска, которые нарушат ограничение закрытой базы.

## Передача и выпуск

Перед изменением контрактов сохраните регрессионный набор и сравните результаты на одном корпусе. Для передачи достаточно ссылки на `main` с SHA, README, этого документа и статуса CI. Для сдачи на платформу выполните отдельный перечень в [delivery.md](delivery.md). Версию и журнал изменений обновляйте в `psb/__init__.py` и `CHANGELOG.md`. Условия лицензии и допустимость публикации предоставленного корпуса согласует владелец проекта.
