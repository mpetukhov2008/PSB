# Корпус и редакции

## Предоставленный ZIP

```bash
python scripts/prepare_data.py data/knowledge-base.zip --output data/knowledge.json
```

Для текущего кейса импортированы 21 документ: 8 документов компании и 13 законодательных
текстов. Содержимое архива не извлекается на файловую систему и не исполняется.
Проверяются расширения, пути, повторные имена и размеры; повреждённые документы
не пропускаются молча. Исходный ZIP остаётся неизменным.

У документа есть ID, название, family, вид law/company, редакция, интервал действия,
дата выгрузки (для законов), имя оригинала и SHA-256. У раздела — locator и точный text.
ID зависит от имени файла; после изменения текста изменяется fingerprint всей базы.
Не переименовывайте исходники между измерениями без необходимости.

Пункты договоров выделяются по номерам. Большие законодательные тексты делятся
по абзацам и границам предложений/слов, с перекрытием. Конец документа не обрезается.

Явная строка-инструкция для ИИ в служебной записке сохраняется в оригинальном тексте
и представлении документа, но отмечена untrusted_instruction и не попадает в индекс.
Это частная защита от очевидной инъекции, не гарантия против всех атак.

## Редакции

Интервал начала включителен, конца — исключителен. Редакции одной family не пересекаются.
Два регламента связаны одной family: старая редакция заканчивается 2025-03-01,
новая начинается с этой даты. Метаданные извлекаются из самого текста.

Допсоглашение — отдельный документ, связанный related_ids с договором.
Контекст сохраняет условие применения нового адреса к спецификациям после указанной
даты; простая замена адреса всего договора была бы неверна.

У законов snapshot_date — дата выгрузки. Из неё не выводится дата принятия или
полный период действия каждой нормы. Для запроса ранее снимка недоступные исторические
законы исключаются. Исторический ответ возможен только по предоставленным основаниям;
при необходимости недостающей нормы требуется частичный ответ или уточнение.

## Произвольные документы

Если автоматический импорт не может явно определить дату документа компании,
используйте существующий импорт по манифесту:

```json
{
  "corpus_kind": "provided",
  "documents": [{
    "id": "agreement-1",
    "title": "Название договора",
    "family": "agreement-1",
    "kind": "company",
    "revision": "Редакция от 2026-01-01",
    "effective_from": "2026-01-01",
    "effective_to": "",
    "file": "originals/agreement.txt"
  }]
}
```

```bash
python scripts/import_corpus.py --manifest data/manifest.json --output data/knowledge.json
```

Этот маршрут поддерживает TXT, MD, DOCX и текстовый PDF. Для PDF установите
requirements-import.txt. Пустые страницы требуют OCR или ручной подготовки.
Манифест и оригиналы размещаются в одной папке; выход за неё запрещён.
Сверка сумм, дат, пунктов и юридического смысла с оригиналом остаётся обязательной.
